# AI-Powered Nutrition Agent

## Overview
This project is an AI-powered Nutrition Agent built using LangFlow, IBM watsonx.ai, and IBM Granite Models.

## Features
- Personalized diet recommendations
- Nutrition tracking
- Health advisory system
- RAG-based food information retrieval
- Dashboard visualization

## Technologies Used
- LangFlow
- IBM watsonx.ai
- IBM Granite-4.0-8B-Instruct
- RAG
- FAISS Vector Database
